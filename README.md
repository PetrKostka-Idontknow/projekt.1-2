# Výlety po Česku

Jednoduchá responzivní stránka s tipy na výlety. Je napsaná v HTML a CSS,
nepotřebuje instalaci ani build.

Otevři `index.html` v prohlížeči. Odkazy na další informace najdeš u
jednotlivých míst a v patičce stránky.

Citace zdrojů a informace o použití AI jsou v souboru [citace.md](citace.md).

## Zdroje informací

- [Prague City Tourism](https://www.prague.eu/cs)
- [Oficiální stránky Českého Krumlova](https://www.ckrumlov.info/cz/)
- [Správa Krkonošského národního parku](https://www.krnap.cz/)

Texty byly připraveny s pomocí GitHub Copilotu v Copilot SDK ve VS Code.
Prompt: „Vytvoř jednoduchou jednostránkovou stránku s tipy na výlety po Česku.“
Konkrétní model nebyl uveden.

## Validace

Zdrojové soubory `index.html` a `style.css` byly odeslány do Nu HTML Checkeru
a W3C CSS validátoru dne 27. 10. 2026. Oba validátory vrátily nula chyb.
